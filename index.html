OME-Zarr, served as IIIF

Four published microscopy images from the Image Data Resource, each exported by ziv into a static IIIF Image API 3.0 Level 0 tile tree. There is no server here: every file a IIIF client will ever request was written ahead of time and is being served by GitHub Pages.

ziv on GitHub Images © their authors, via IDR

Each demo is a real IIIF service, not a picture of one. The info.json below every demo is a live endpoint: paste it into Mirador, the Universal Viewer, or any other IIIF client and the image opens there, with no knowledge of OME-Zarr on the client's part. Every demo also carries a IIIF Presentation manifest, so each one opens directly in Mirador from its card.

Each demo also links to the original OME-Zarr store in vizarr, so you can compare what a IIIF client sees against the chunked array the data actually lives in.

Demos

Nuclear segmentation

236 z-planes with a segmentation mask on every one. The label picker draws the mask in ziv's deterministic distinct colours, because all 61 colours this image declares are the identical grey: rendering the declared table faithfully collapses nineteen nuclei into one shape.

275 × 271 px · 236 z · 2 channels · 1 label

Whole brain

255 megapixels in one plane, nine pyramid levels, for deep zoom. Well over the 64-megapixel whole-image cap, so the export declares only the whole-image sizes it actually wrote rather than advertising renderings it would refuse to serve.

19 120 × 13 350 px · 9 levels · 3 channels

In situ genome sequencing

Its segmentation mask is stored as 64-bit integers, a sample type ziv silently dropped until recently: the image opened, the label did not, and nothing said so. It now renders, and a label that cannot be opened is reported by name.

Declares two separate label images, Cell and Chromosomes, so the picker has a genuine choice rather than a single mask to toggle. Each is its own multiscale image beside the intensity data.

How these were made

Each demo is one command against the published store, with the URL it will be hosted at baked into every info.json:

ziv export https://uk1s3.embassy.ebi.ac.uk/idr/zarr/v0.4/idr0062A/6001240.zarr ./nuclear-segmentation --id https://nishad.github.io/ziv-demos/nuclear-segmentation --planes --labels

The exact commands live in scripts/build-demos.sh, which regenerates the whole site.

All four images are published in the Image Data Resource and remain the work of their authors, credited above with their primary publications. Please cite those papers, and IDR, rather than this site. Image reuse is governed by the terms stated on each study's IDR page.

Built with ziv. The viewer bundled into each demo is OpenSeadragon. The comparison links open vizarr, which reads the original OME-Zarr store directly in the browser.
